# Borderless Workboard

ボーダレスジャパン向けの社内プロジェクト管理・OKRモニタリングツールです。  
サーバー不要のシングルファイルHTML製ツール群で、ブラウザで即座に動作します。

## ツール一覧

| ファイル | 説明 |
|---------|------|
| `プロジェクト管理.html` | OKR・プロジェクト・タスク・KPIモニタリング統合ダッシュボード |
| `タスク管理.html` | カンバン式タスク管理（ToDo / 対応中 / 完了） |
| `timer.html` | カウントダウンタイマー |

## 機能

### プロジェクト管理.html（メインツール）
- **ダッシュボード** — 4組織のOKR達成率・進行中プロジェクト・直近タスクを一覧表示
- **OKR管理** — 2026年度OKRをプリセット。各KRに実績値を入力すると達成率を自動計算
- **プロジェクト管理** — プロジェクト登録・OKR Key Resultとの紐付け・マイルストーン管理・Notionリンク
- **タスク管理** — カンバンボード（プロジェクトとの紐付け対応）
- **KPIモニタリング** — Google Sheets API v4 連携で実績データを自動取得・可視化
- **Notion連携設定** — 各組織ごとに複数のNotionデータベースを設定可能（Cloudflare Workerプロキシ経由）
- **Google Sheets設定** — 各組織ごとに複数のスプレッドシートを設定可能

### 対象組織
- HRスタジオ
- PRスタジオ
- コーポレート（財務・労務・法務・情シス）
- グループ経営強化

## 使い方

### クイックスタート
HTMLファイルをダブルクリックするだけで起動します。インストール不要。

### ローカルサーバーで開く（推奨）
```bash
python3 -m http.server 3000
```
→ http://localhost:3000/プロジェクト管理.html

### Web公開（Cloudflare Pages）
`プロジェクト管理.html` を `index.html` にリネームして Cloudflare Pages にアップロード。  
Cloudflare Access と組み合わせることで、特定メンバーのみアクセス可能なツールとして運用できます。

## データ保存

すべてのデータはブラウザのlocalStorageに保存されます。  
設定 → データをエクスポートからJSONファイルとしてバックアップできます。

## 外部連携

| サービス | 用途 | 設定方法 |
|---------|------|---------|
| Google Sheets API v4 | KPI実績データの取得 | 設定タブ → 各組織 → Googleスプレッドシート |
| Notion API | タスクデータの同期 | 設定タブ → 各組織 → Notion連携（Cloudflare Worker必要） |

## 開発ツール構成

- `.claude/launch.json` — ローカル開発サーバー設定（`python3 -m http.server 3000`）
